HPG SCIENTIFIC MEETING — NETLIFY PACKAGE

1. Put your real files in the assets folder using these exact names:
   logo.png, speaker.jpg, background.mp4, video-poster.jpg,
   sponsor1.png, sponsor2.png, favicon.png
2. Edit the event text in index.html.
3. Edit EVENT_DATE and Google Calendar data in script.js.
4. To receive RSVP responses, create a Formspree form and paste its endpoint
   into FORMSPREE_ENDPOINT in script.js.
5. Drag the complete HPG-Scientific-Meeting folder (or this ZIP) into Netlify Drop.

Important: the page works without the optional media, but shows best after adding it.
